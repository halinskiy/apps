A few little Mac apps

macOS menu-bar utilities. Apple Silicon, macOS 12+. Signed & notarized by Apple, so they just open.

Pet in The System

A tiny pixel pet that roams across your windows, sleeps, falls when you grab a window, and gets thrown when you drag & drop it.

Download PTS

WGrid

Snap windows into clean grids (1×1 to 3×3), drag to rearrange. Lives in the menu bar.

Download WGrid

Quirky

Capture toolkit: OCR text off the screen, color eyedropper, pixel measuring, and pull DOM/SVG out of browsers.

Download Quirky

Voicer

Hold Fn and talk: local Whisper large-v3-turbo turns Russian speech with English tech terms into text in any window (made for Claude Code in the terminal). Optional LM Studio pass fixes terms. Nothing leaves the Mac.

Download Voicer

Each app opens the .dmg → drag it into Applications → launch it from there. They live in the menu bar (top-right), not the Dock. On first run macOS asks for one permission — Accessibility for PTS, WGrid & Voicer (Voicer also asks for the microphone), Screen Recording for Quirky — grant it, then relaunch.
